# 레퍼런스 케이스 — 오피스텔 임차인 / 현관등 발화 / 제조물 의심

최종수정: 2026-08-26 (v1)

이 문서는 **실제로 일어난 한 건의 화재**를 기록한다. 용도는 둘이다.

1. **스키마 검증 기준** — 데이터 구조를 짤 때마다 "이 케이스가 처음부터 끝까지
   도는가"를 확인한다. 시나리오 없이 스키마를 짜면 예쁘지만 안 돌아가는 구조가
   나온다.
2. **데모 서사** — "그때 이 서비스가 있었다면" 구성의 원본.

`[확인]` 당사자 진술 · `[미확인]` 물어봐야 할 것 · `[해석]` 우리 판단

## 2. 실제로 일어난 일

### 2-1. 상대해야 했던 사람들 — 순차적으로 등장

**1단계**: 건물 보험사 측 손해사정사와 협의 시작.

**2단계**: 전등 제조사가 처음에는 **협조적인 태도**로 접촉.

**3단계**: 이후 제조사가 **자기 쪽 손해사정사를 고용**하여 대응.

`[확인]` 동시가 아니라 시간차를 두고 진행됨.

`[해석]` 이 시간차가 핵심이다. 동시에 둘이 나타나면 "양쪽이 붙었다"가 바로
보이지만, 순차적이면 **상대의 성격이 도중에 바뀌는 것**이고 그 전환점을
알아채기 어렵다. 협조적이던 시기에 넘긴 자료나 무심코 한 말이 나중에
불리해질 수 있다.

**결과**: 두 손해사정사 모두 각자 고용주의 이익을 대변하는데, 피해자를
대변하는 사람은 없었다. **어느 쪽이 자신에게 유리한지를 본인이 직접 따져야 했다.**

### 2-2. 청소

- 전문 복구업체를 **한 번** 불렀으나 큰 부분만 처리됨.
- 나머지는 **몇 주 동안 직접 청소**.
- **소화약제 분말을 마시면서** 작업. 보호구 안내 없었음.
- 집에 있던 **모든 옷가지를 차에 두 번 나눠 실어** 세탁소로 운반·세탁.

`[확인]` 당사자 진술.

### 2-3. 그동안 몰랐던 것

- 청소를 언제부터 해도 되는지
- 무엇을 먼저 치우고 무엇을 남겨야 하는지
- 보호구가 필요한지, 어떤 등급인지
- 옷을 옮기기 전에 촬영해야 하는지
- 두 손해사정사가 각각 누구를 대변하는지
- 현관등 발화가 자신의 책임 범위인지 아닌지
- 무료로 중립적 판단을 받을 수 있는 곳이 있는지

## 3. 이 케이스가 건드리는 우리 데이터

### 3-1. 사실 축 — 전부 해당되는데 아무도 안 알려줬다

| 우리 데이터 | 이 케이스에서 |
|---|---|
| §1-3 보호구 등급 (최소 N95, 석면 의심 시 P100) | 분말을 마시며 몇 주 청소 |
| §1-2 소화약제 흡입 시 기도·폐 자극 | 그대로 노출 |
| §8-1 분말 신속 제거, 가정용 청소기 금지 | 방법 안내 없음 |
| §2-2 그을음은 섬유에 정전기적으로 부착, 가정 세탁은 오염 확산 | 일반 세탁소로 전량 운반 |
| §4-1 청소·폐기 전 촬영, 보험사 확인 전 폐기 금지 | 안내 없음 |
| §6-1 제품결함 의심 시 원상 보존 | 조사서에 제조물 의심 기재됨 |

`[해석]` **사실 축이 존재해야 하는 이유 자체다.** 조사관은 "저희 조사는
끝났습니다"까지가 역할이고, 그 뒤로 물리적 대응을 알려줄 주체가 없다.

### 3-2. 제도 축

**공용부 발화 → 임차인 책임 아닐 가능성** `[해석]`

조사관 인터뷰에서 정확히 이 케이스가 일반론으로 설명됐다.
"전등에서 불이 났는데 전등 안쪽에서 나버렸어… 세입자가 어떻게 할 수가
없잖아… 건물주가 책임져야 되는 거 아니냐."

→ 사촌동생은 구상권 리스크에서 벗어나는 케이스였을 가능성이 높다.
**그것을 본인이 알았는지가 관건**이다. 몰랐다면 몇 주간 "내가 물어내야 하나"를
안고 있었던 것이고, 그 불안은 앱이 없앨 수 있는 고통이다. `[미확인]`

**화재피해분쟁조정위원회 — 정확히 이 케이스용** `[해석]`

서울시 조례 §7② 조정 대상에 "제조물 결함으로 추정되는 화재조사와 관련된
사항"이 명시. 무료, 접수는 소방재난본부장 또는 관할소방서장, 신청일로부터
40일 이내 개최 의무(§11④).

→ 이것을 알았다면 손해사정사 둘 사이에서 혼자 판단하지 않아도 됐을 수 있다.
단 실제 개최 실적은 미확인(`problem-definition.md` §3-4).

**손해사정사 이관 논리의 빈 곳** `[해석]`

우리는 보험·제조물 영역을 "손해사정사·전문가에게 넘긴다"로 설계했다.
그런데 이 케이스는 **넘길 데가 없다.** 나온 손해사정사 둘 다 상대측이다.
이관처가 있는 것과 내 편인 이관처가 있는 것은 다르다.

### 3-3. 미확인 — 사촌동생에게 물어볼 것

- 시간순 타임라인: 화재일 / 건물 보험사 손해사정사 접촉일 / 제조사 초기 접촉일 /
  제조사 손해사정사 등장일 / 화재현장조사서 수령일 / 청소 시작·종료일
- 화재현장조사서를 어떻게 받았는가 (정보공개청구 직접? 손해사정사 위임?)
- 국과수 또는 화재감정 의뢰가 있었는가, 있었다면 소요 기간
- 현관등 발화가 본인 책임이 아닐 수 있다는 것을 알고 있었는가, 언제 알았는가
- 임시 거처는 어떻게 해결했는가
- 최종적으로 어느 쪽 보험으로 처리됐는가, 얼마나 걸렸는가
- 자치구는 어디였는가 (조례 적용 여부 판정)

→ **타임라인 데이터의 실측값**이 된다. 현재 우리 시간 데이터는 전부 문헌값이다.

## 4. 데모 구성 — "그때 이 서비스가 있었다면"

좌: 실제로 있었던 일 / 우: 앱이 있었다면. 세 화면.

### 화면 1 — 화재 당일

**실제**: 조사관이 명함을 주고 감. 이후 무엇을 해야 할지 모름.

**앱**:
- 분말 청소 시 최소 N95, 석면 의심 시 P100 (진공청소기 사용 금지)
- 젖은 가전·전자기기 전원 인가 금지
- 옷·물건을 옮기기 전에 방마다 광각+근접 촬영
- 현관등 발화 → 제품·잔해 보존, 임의 폐기·청소 금지
- 현재 보존조치 중이면 아직 치우면 안 됨

### 화면 2 — 손해사정사가 왔을 때

**실제**: 건물 보험사 측 손해사정사와 협의 → 제조사가 협조적으로 접촉 →
이후 제조사가 손해사정사 고용. 어느 쪽이 유리한지 혼자 판단.

**앱**:
- 이 사람은 건물 보험사가 고용한 대리인이다
- 제조사가 협조적으로 나와도 아직 입장이 정해지기 전일 수 있고,
  손해사정사가 붙는 시점이 온다
- 둘 다 당신의 대리인이 아니다
- 현관등(공용부) 발화라면 임차인 책임 범위 밖일 가능성 — 확인해볼 것
- 무료 분쟁조정 신청 가능, 소방서 접수, 40일 이내 개최

### 화면 3 — 몇 주 뒤

**실제**: 직접 청소. 옷 전량을 차로 운반.

**앱**:
- 화재현장조사서가 실질적으로 더 중요 — 정보공개청구로 신청
- 감정이 들어가면 두 달 이상 걸릴 수 있음. 기다리는 동안 할 일과 대기할 일 구분
- 그을음 밴 섬유는 일반 세탁으로 오염이 확산될 수 있음
- 지금이 무엇을 기다리는 시간인지

### 지역 비교 레이어

이 사례 위에 얹는다. "같은 일이 강남에서 났다면 폐기물 처리비 지원이 있었다."
자치구를 바꾸면 답이 달라지는 것을 한 화면에서 보여준다.

## 5. 스키마 검증 체크리스트

데이터 구조를 짤 때마다 아래가 표현 가능한지 확인한다.

- [ ] 임차인 / 보험 미가입 / 건물 보험만 존재 조합을 표현할 수 있는가
- [ ] 발화 지점이 공용부인지 전용부인지를 조건으로 쓸 수 있는가
- [ ] 제조물 결함 의심 여부를 조건으로 쓸 수 있는가
- [ ] "이 사람은 누구를 대변하는가"를 표현할 수 있는가
- [ ] 상대의 입장이 시간에 따라 바뀔 수 있다는 예고를 표현할 수 있는가
- [ ] 화재현장조사서 발급 대기(보름~2개월+)를 "대기 중" 상태로 표현할 수 있는가
- [ ] 사실 축(분말·보호구·촬영)과 제도 축(보험 협의 후 청소)의 순서 충돌을
      해결할 수 있는가 — "빨리 치워야 하는데 그 전에 보험사 협의가 필요하다"
- [ ] 자치구를 바꾸면 결과가 달라지는가

## 6. 일반화 주의

**N=1이다.** 이 사례 하나로 일반화할 수 없는 것들:

- 손해사정사가 순차적으로 등장하는 패턴이 제조물 의심 케이스에서 일반적인지
  → 조사관 추가 인터뷰에서 확인
- 오피스텔 + 임차인 + 공용부 발화 + 제조물 의심 조합의 빈도

**다만 배경이 뒷받침된다.** 조사관 인터뷰에서 일반론으로 설명된 구조 —
세입자는 대부분 보험이 없고, 구상권 대상이 되며, 공용부 발화면 건물주 책임 —
가 이 사례에서 그대로 재현됐다. 조사관이 "흔한 패턴"이라고 말한 것의 실례다.
